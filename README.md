# 🧾 User Management API – CRUD Backend

## ✨ What's This All About?

Hey dev! Welcome to **User Management API**, a simple yet effective backend project built with **Node.js**, **Express**, and **MySQL**, designed to manage users through a complete set of **CRUD** operations.

Whether you're testing a frontend, learning how REST APIs work, or bootstrapping your own admin panel—this project provides the foundation you need. Plus, it includes a basic **authentication endpoint** for user registration.

---

## 🔎 Features

- 📄 **Create, Read, Update, and Delete** users from the database.
- 📬 **Register new users** securely via `/auth/register`.
- ⚙️ Organized architecture with clean code structure.
- 🗂️ Sequelize ORM integration with MySQL for smooth DB operations.
- 🌐 RESTful API design for easy integration with frontend apps.
- 🔐 Uses environment variables for sensitive configuration.

---

## 🛠️ Tech Stack

- **Node.js** – Backend runtime environment  
- **Express.js** – Web framework for routing  
- **Sequelize** – ORM for SQL databases  
- **MySQL2** – Database connector  
- **Dotenv** – Environment configuration  
- **Nodemon** – Hot reload during development
